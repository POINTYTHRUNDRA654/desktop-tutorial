# AI Voice Generation Guidelines for Fallout 4 Modding

## ⚠️ Important: When to Use AI vs. Real Voice Actors

### AI-Generated Voices Are Best For:
- **Prototyping & Testing** - Quickly test dialogue flow and timing before investing in voice actors
- **Placeholder Content** - Development phase content that will be replaced later
- **Minor NPCs** - Background characters with minimal dialogue requirements
- **Automated Systems** - Terminal messages, robot dialogue, system announcements
- **Narration Drafts** - Test read-through of quest lines before hiring talent

### Real Voice Actors Are Best For:
- **Main Quest Dialogue** - Quality is critical for player experience
- **Key NPCs** - Important characters that players will interact with repeatedly
- **Companion Followers** - Characters players spend significant time with
- **Mod Distribution** - Any mod you plan to publish on Nexus or share publicly

## 🎭 Why Professional Voice Acting Matters

### Community Quality Standards
Fallout 4 mod community expects professional voice acting for:
- Quest mods with main characters
- Follower/companion mods
- Full story expansions
- Dialogue-heavy content

### AI vs. Real Actor Comparison

| Aspect | AI Voices | Real Voice Actors |
|--------|-----------|------------------|
| **Quality** | Robotic, inconsistent emotion | Natural, authentic performance |
| **Consistency** | Varies between lines | Professional sound design |
| **Performance** | No acting interpretation | Professional interpretation |
| **Fallout 4 Fit** | Generic sounding | Can match game aesthetic |
| **Mod Competitiveness** | Lower appeal | Higher downloads/endorsements |
| **Production Time** | Minutes | Days/weeks (worth the wait) |
| **Cost** | Free/$$ | $ (affordable voice actors exist) |

## 💼 Hiring Voice Actors

### Budget-Friendly Options
- **Fiverr** - Affordable voice acting gigs ($5-50 per line)
- **Upwork** - Freelance voice actors with Fallout 4 experience
- **Voice Acting Communities** - Reddit /r/VoiceActing, Discord servers
- **Local Theater/Drama Schools** - High-quality local talent

### What to Expect
- **Script Preparation** - Have dialogue ready and organized
- **Direction** - Provide examples of Fallout 4 NPC voices for reference
- **Revision Rounds** - Usually 1-2 revision opportunities included
- **Typical Cost** - $50-500 depending on scope (5-50 lines)
- **Turnaround** - 1-2 weeks typical

## 🎯 Recommended Workflow

### Phase 1: Development (Use AI)
```
1. Write quest/dialogue script
2. Use Mossy AI voices for timing/flow testing
3. Record video/audio tests
4. Get feedback from testers
5. Refine dialogue based on feedback
```

### Phase 2: Production (Hire Voice Actors)
```
1. Finalize script with tested timings
2. Create voice actor briefing document
3. Send voice lines to actor(s) with Fallout 4 references
4. Record and receive audio files
5. Integrate into mod using CK
6. Sync lip-animations with real audio
```

### Phase 3: Release (Final Polish)
```
1. Quality check all dialogue
2. Mix audio (optional but recommended)
3. Publish to Nexus
4. Credit voice actors in mod description
```

## 🔧 Using Mossy for AI Voice Generation

### Quick Start
1. Open Mossy → AI Voice Generation platform
2. Select a voice profile (Fallout4-Male-Human, etc.)
3. Enter dialogue text
4. Click "Generate Voice"
5. Test audio playback
6. Export as WAV for integration

### Batch Generation
- Generate multiple lines in one session
- Create NPC dialogue lists
- Auto-generate lip-sync data
- Export as batch dialogue package

### Voice Cloning (Advanced)
- Provide your own voice sample (WAV)
- Mossy creates custom voice profile
- Use cloned voice for character-specific testing
- Useful for director's reference audio

## 📋 Quality Checklist Before Publishing

Before uploading to Nexus:
- [ ] All dialogue is voice acted (or intentionally no dialogue)
- [ ] Voice files integrated properly with CK
- [ ] Lip-sync animations match voice timing
- [ ] Audio levels are consistent
- [ ] No robotic/AI artifacts in final audio
- [ ] Voice actors credited in mod description
- [ ] Tested with game's audio system

## 🚫 What NOT to Do

❌ **Don't publish mods with only AI voices** - Players notice immediately
❌ **Don't mix AI and real voices** - Inconsistency is jarring
❌ **Don't forget to credit voice actors** - Builds community relationships
❌ **Don't use low-quality voice files** - Affects mod perception
❌ **Don't skip testing** - Audio integration bugs are common

## ✅ Best Practices

✅ **Test audio integration early** - Sync issues are easier to fix during development
✅ **Use Mossy for prototype iterations** - Fast feedback loop saves money
✅ **Provide voice actors with context** - Emotion, pace, character details
✅ **Get multiple takes** - Directors usually provide variation options
✅ **Credit generously** - Good relationships lead to future collaborations
