## ❓ Common Questions

### Q: Will the validation script block legitimate code?
**A:** No. It only blocks files outside allowed paths OR files in blocked paths. React components in `src/renderer/src/` are always allowed.

### Q: What if I need to modify a blocked path?
**A:** That's a sign the task should be different. Blocked paths (Electron, IPC, secrets) are excluded because agents shouldn't touch them. Manual work only.

### Q: Can I edit allowed/blocked paths?
**A:** Yes, edit `.antigravity.config.json`. But be careful—these guardrails exist for security.

### Q: What if the agent generates bad code?
**A:** You review it before merge. If quality is low, refine `.antigravity-skills.md` and retry the task.

### Q: Can agents work in parallel?
**A:** Yes! You can assign tasks on multiple feature branches. Each validates independently.

### Q: Is this ready for production?
**A:** Yes. The setup is security-hardened. Agents can't bypass the validation script, and all code gets human review before merge.
