# Sim Settlements 2 Creator Toolkits (Updated 2026)

This guide is the up-to-date quick reference for the three SS2 creator tools now in Mossy’s download list:

- **Add-On Maker’s Toolkit** — Nexus #48521  
- **Wasteland Reconstruction Kit (WRK)** — Nexus #48960  
- **City Plan Contest Assistant** — Nexus #50366  

---

## 1) Add-On Maker’s Toolkit (Nexus #48521)

**What it is:**  
Official SS2 learning bundle with PDFs, helper files, and xEdit scripts for creating SS2 content (buildings, city plans, leaders, holidays, newspaper content, brewery recipes, unlock integrations, and more).

**Who it’s for:**  
Beginner-to-intermediate addon authors, especially first-time modders.

**How to use it (quick start):**
1. Download and extract the toolkit.
2. Read the beginner PDF track first (don’t skip the setup sections).
3. Install required tools (Creation Kit + xEdit workflow).
4. Build one small test addon before attempting full packs.
5. Validate in-game early and often.

**Best practice:**  
Treat this toolkit as your primary SS2 authoring baseline and keep it updated when the mod page updates.

**Credit:**  
Sim Settlements 2 development resources and tutorials by the SS2 team.

## 2) Wasteland Reconstruction Kit (WRK) (Nexus #48960)

**What it is:**  
A large SS2-focused build kit exposing **10,000+ buildable items**, SS2 prefabs, and specialized scripted settlement tools.

**Who it’s for:**  
City plan designers, settlement artists, and addon creators who need high-volume build assets and SS2-compatible prefab workflows.

**Core features for creators:**
- Massive workshop item catalog for city plans/layouts
- SS2 prefab structures and custom model variants
- Scripted placement helpers (markers, patrol tools, effect emitters, etc.)
- Better sharing workflow with SS2/Workshop Framework exports

**Requirements:**  
Sim Settlements 2 + Workshop Framework (+ DLC for authoring-side access to certain buildables).

**How to use it safely:**
1. Build using WRK assets while designing your city plan.
2. Run settlement checks and pathing checks before export.
3. Export and test in a clean profile/save.
4. Verify missing-content fallback behavior before publishing.

**Credit:**  
WRK is a Sim Settlements community effort led by Strong Swanson with SS2 team and contributor support (full credits listed on the mod page).

---

## 3) City Plan Contest Assistant (Nexus #50366)

**What it is:**  
A utility mod built to make monthly SS2 City Plan Contest participation much easier.

**Who it’s for:**  
Contest participants and creators who want faster setup, fewer export mistakes, and better contest compliance checks.

**What it automates:**
- Contest settlement setup and unlock flow
- Build-limit and contest-state setup tasks
- Validation helpers via holotape tools
- Export-friendly replacement behavior for moved/picked vanilla items

**How to use it (contest workflow):**
1. Install and update it on/after the monthly rollover window.
2. Use contest setup tools before serious building begins.
3. Use the holotape checks before export.
4. Export, re-test, and package for submission.

**Credit:**  
City Plan Contest Assistant tooling provided by the SS2 creator ecosystem; full permissions/credits remain on the Nexus page.
