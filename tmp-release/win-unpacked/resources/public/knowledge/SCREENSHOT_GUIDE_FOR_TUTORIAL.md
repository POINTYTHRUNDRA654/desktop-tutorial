## How to Use These Screenshots

### For Tutorial Writers

**Option 1: Reference Visual Guide Screenshots**
```markdown
![The Auditor](visual-guide-images/Page%2025%20the%20auditor..png)
*The Auditor interface for file analysis*
```

**Option 2: Reference Core Interface Screenshots**
```markdown
![Chat Interface](docs/screenshots/chat-interface.png)
*The chat interface with message history*
```

### For New Screenshots

If you need to add NEW screenshots not covered by the existing 55+:

1. **Capture**: Use `Win + Shift + S` (Windows) or similar
2. **Name**: Use descriptive names matching the pattern:
   - For visual guide: "Page X, feature name.png"
   - For quick reference: "feature-name-description.png"
3. **Save**: Place in appropriate directory
4. **Reference**: Update documentation with proper paths
