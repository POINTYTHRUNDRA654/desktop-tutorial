================================================================================
                            HOW IT WORKS
================================================================================

User Input Flow:
  User types message
    ↓
  ChatInterface (React)
    ↓ (IPC)
  Electron Main Process
    ↓ (HTTP POST)
  Backend Server (localhost:8787)
    ↓ (API Call)
  Groq/OpenAI API
    ↓ (Response)
  Backend → Main → ChatInterface
    ↓
  TTS Engine (mossyTts.ts)
    ↓
  Browser Speech API
    ↓
  🔊 Audio Output - Mossy speaks!

Fallback System:
  If backend fails → Use local API keys
  If API keys missing → Show error message
  If TTS fails → Display text only
