📋 ISSUE REPORTED
─────────────────
User was stuck in "Feed Me the Base Game" step:
  ❌ Cannot scroll down
  ❌ Cannot go back  
  ❌ Cannot skip
  ❌ Completely trapped in the UI

🔍 ROOT CAUSES IDENTIFIED
──────────────────────────
1. Container Height Conflicts
   • h-full + min-h-[600px] + max-h-[90vh] = layout chaos
   • flex-1 on scroll container competing with sticky footer
   • Double scroll zones (parent + child both overflow-y-auto)

2. Missing Button State Feedback
   • "Skip for now" button appeared clickable during digest
   • No visual feedback that navigation was blocked
   • Users felt stuck even though button was technically present

3. Z-Index Stack Issues
   • Footer could be rendered behind scroll content
   • Buttons visible but not clickable

✅ FIXES APPLIED
────────────────
1. Scroll Container (Lines 1761-1763)
   BEFORE: <div className="... h-full min-h-[600px] max-h-[90vh]">
           <div className="overflow-y-auto flex-1 ... min-h-0">
   
   AFTER:  <div className="flex flex-col animate-fade-in">
           <div className="overflow-y-auto max-h-[calc(90vh-200px)] ...">
   
   ✓ Removed conflicting height constraints
   ✓ Single explicit max-height with 200px reserved for buttons
   ✓ Clean, predictable scroll behavior

2. Skip Button State (Lines 2626-2630)
   BEFORE: <button onClick={handleSpriggitContinue} className="...">
   
   AFTER:  <button onClick={handleSpriggitContinue}
                   disabled={spriggitStatus === 'running'}
                   className="... disabled:opacity-50 disabled:cursor-not-allowed">
   
   ✓ Button disabled during digest operation
   ✓ Visual opacity feedback (50%)
   ✓ Cursor changes to not-allowed
   ✓ Clear UI state indication

3. Footer Z-Index (Line 2597)
   BEFORE: <div className="flex-shrink-0 ... bg-slate-900">
   
   AFTER:  <div className="flex-shrink-0 ... bg-slate-900 relative z-10 mt-4">
   
   ✓ Explicit z-index keeps footer on top
   ✓ margin-top adds visual separation
   ✓ Guarantees button clickability
